# Restaurant-billing-system
A simple Restaurant Billing System built using Python. It allows users to view the menu, place orders, calculate the subtotal, add 5% GST, and generate the final bill.
🍽️ Restaurant Billing System

A simple Restaurant Billing System developed using Python. 

📌 Features

- Display restaurant menu
- Select food items
- Enter quantity
- Calculate subtotal
- Calculate 5% GST
- Generate final bill
- Simple and easy-to-use console interface

🛠️ Technologies Used

- Python 3
- Dictionaries
- Lists
- Functions
- Loops
- Conditional statements
- Basic input/output

▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

python restaurant_billing.py

📋 Example

The user can select items from the menu, enter the quantity, and the program will automatically calculate the subtotal, GST, and final bill.

🎓 Project Purpose

This project was created as a B.Tech 1st-year Python project to practice fundamental programming concepts and build a simple real-world application.
