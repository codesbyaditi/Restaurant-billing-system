🍽️ Restaurant Billing System

This is a simple Restaurant Billing System made using Python.
It is a console-based project where the user can enter their name, see the menu, select items, enter the quantity, and get the final bill.

📌 Features

- Asks for customer name
- Shows the restaurant menu
- Allows the user to select food items
- Takes quantity from the user
- Calculates the total amount
- Adds 5% GST
- Gives 10% discount on bills of ₹500 or more
- Displays the final bill

🛠️ Technologies Used

- Python 3
- Lists
- Dictionaries
- Loops
- If-else statements
- Functions
- Basic input and output

▶️ How to Run

1. Install Python 3 on your computer.
2. Download the project files.
3. Open the project folder.
4. Open the terminal in that folder.
5. Run the program using:

python restaurant_billing.py

📋 How It Works

First, the program asks the user to enter the customer name.

Then, it displays the restaurant menu with different food items and their prices.

The user enters the item number and quantity. The program calculates the price of the selected items.

After the user finishes ordering, the program calculates:

- Subtotal
- Discount (if applicable)
- 5% GST
- Final bill amount

Finally, the program displays the customer name and final bill.
